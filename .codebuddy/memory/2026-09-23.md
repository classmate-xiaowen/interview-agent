## 接入阿里云百炼（Bailian）作为默认大模型
- 切换后端默认模型供应商为阿里云百炼（OpenAI 兼容模式）。
- `backend/app/config.py` 默认值改为：`llm_base_url=https://dashscope.aliyuncs.com/compatible-mode/v1`、`llm_api_key="YOUR_BAILIAN_API_KEY"`（占位，需用户填真实 DASHSCOPE_API_KEY）、`chat_model=guardrail_model="qwen-plus"`、新增 `llm_provider="bailian"`。
- `backend/app/services/llm.py` 的 `_thinking_extra()` 改为仅当 `llm_provider=="deepseek"` 且 `llm_disable_thinking=True` 时才下发 DeepSeek 专属的 `chat_template_kwargs.enable_thinking=False`；百炼 qwen 不识别该参数，否则会报错。
- 新建 `backend/.env.example`（README 引用但此前缺失），并把 README 第 4 步与底部提示的 DeepSeek 说明改为百炼。
- 说明：百炼亦提供 `text-embedding-v3`（compatible-mode 可用），知识库 Embedding 可一并切到百炼；当前默认仍走 OpenAI，已在 .env.example 注释给出百炼写法。
